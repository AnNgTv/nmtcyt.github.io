🧭 Cách tham gia

  1. Mở Minecraft Java hoặc Bedrock.
  2. Chọn Multiplayer / Servers → Add Server.
  3. Nhập địa chỉ máy chủ ở phía trên.
  4. Tham gia và làm theo hướng dẫn trong game.

🔐 Auth hoạt động thế nào?

AuthMe trong game không đồng nghĩa với tài khoản website. Muốn dùng chung tài khoản cần backend hoặc API tích hợp phù hợp.

💳 Nạp tiền có tự động không?

Chưa. Cần API cổng nạp thẻ hoặc dịch vụ thanh toán ngân hàng và backend kiểm tra giao dịch.
